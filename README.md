# ESXForge — Sell ESX Scripts & Earn | FiveM Marketplace, Servers & Community

**ESXForge** is a FiveM **ESX** platform: **sell your scripts and earn income** (Stripe Connect, 90% seller / 10% platform on marketplace sales), **list roleplay servers**, and use a **marketplace**, **forum**, and **community feed** for server owners, developers, and players.

## Why ESXForge

- **Creators** — List ESX resources, connect **Stripe**, get paid on sales, track payouts in settings.  
- **Buyers** — Listings, reviews, secure checkout.  
- **Servers** — Discovery for **FiveM ESX** roleplay communities.

## Tech stack

React (Vite), TypeScript, Tailwind CSS, Supabase, Stripe (Connect + Checkout), Node/Express (webhooks & APIs).
